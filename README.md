# Lexical Analyzer in C

## Overview
This project implements a simple lexical analyzer using C language.

The lexical analyzer reads source code and identifies:
- Keywords
- Identifiers
- Operators
- Constants
- Special Symbols

## Features
- Detects C keywords
- Identifies variables and constants
- Recognizes operators and delimiters
- Ignores whitespaces

## Technologies Used
- C Programming
- GCC Compiler

## Sample Input
int a = 10;

## Sample Output
int -> Keyword
a -> Identifier
= -> Operator
10 -> Constant
; -> Special Symbol
